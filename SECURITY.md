# Security

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/kristoffervp/skolemelding-mcp/security/advisories/new), not in a public issue. Describe what you found and how to reproduce it.

Never include sign-in files from `.data/`, tokens, or the content of real school messages, in a report or an issue.

## Supported versions

Only the latest release gets fixes.

## Scope

This covers the code in this repository: the local server, the sign-in flow, file handling, and the sending tools. Problems in the Skolemelding service itself belong to Oslo kommune, not to this project.
